# References

Each principle and method the learner uses, where it is used, and the methods queued to try at each stage. For how this project relates to recent work on sleep and learning to learn, see [RELATED_WORK.md](RELATED_WORK.md).

Rules for this file:
- Only sources someone has actually checked go in: classics with their standard citation, and recent papers whose page was opened during the project.
- "Used" means running code. "To try" means it's planned as a swappable recipe option (`learner/recipe.py`), and its result will be reported against the current one.
